# Gejogames

Small games about the land — free browser games about farming,
nature and conservation. No downloads, no sign-ups.

🎮 Play: **[gejogames.com](https://gejogames.com)**

## Open tools

- **[three-bits](https://github.com/Gejogames/three-bits)** — small, copyable three.js snippets with live demos
- **[sfx-web](https://github.com/Gejogames/sfx-web)** — zero-asset WebAudio sound effects library
- **[devlog-md](https://github.com/Gejogames/devlog-md)** — markdown-file blog starter for Next.js
- **[link-little](https://github.com/Gejogames/link-little)** — zero-build link-in-bio template
